# Tareas

Tareas sueltas que no son una práctica numerada del manual.

Cuando el profesor asigne una, crear una carpeta `YYYY-MM-DD-tema/` (no usar `pendientes/` para el trabajo final):

```
tareas/
  2026-08-25-investigacion-rfc/
    README.md          enunciado
    desarrollo.md
    evidencias/
    entrega/
```
