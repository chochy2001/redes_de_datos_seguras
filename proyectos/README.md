# Proyectos

Proyectos del curso (Packet Tracer, diseño de red, integradores, etc.).

Un proyecto = una carpeta:

```
proyectos/
  01_nombre_corto/
    README.md          objetivo, alcance, integrantes
    docs/              especificación y bitácora
    topologias/        .pkt / .pka
    configs/           IOS, Linux, scripts
    evidencias/
    entrega/           PDF / video / archivos finales
```

No subir ISOs, OVAs ni discos virtuales (van en `.gitignore`).
